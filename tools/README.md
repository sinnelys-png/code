# Вспомогательные скрипты

Запускаются из корня репозитория, нужен Node.js 18+.

## Метки версий — `node tools/stamp-versions.js`

Дописывает к стилям и скриптам в `site.html` и `index.html` метку по содержимому файла
(`css/public.css?v=1a2b3c4d`). Файл изменился — метка другая, и браузеры скачивают его
заново, а не показывают старый из кэша (не нужно жать Ctrl+F5).

Запускается сам перед каждым коммитом — хук `tools/hooks/pre-commit`. На новом компьютере
(после `git clone`) хук нужно один раз включить:

```
git config core.hooksPath tools/hooks
```

Проверка: `git config core.hooksPath` выводит `tools/hooks`.

## Проверка разбора анкет — `node tools/anketa-check.js`

Разбирает все анкеты из таблицы нынешним `js/pages/anketa.js` и сравнивает с прошлым разбором.

- `node tools/anketa-check.js --update` — запомнить нынешний разбор (снимок);
- `node tools/anketa-check.js` — показать, у кого и какое поле изменилось после правки парсера;
- `node tools/anketa-check.js Виски` — разбор одной анкеты целиком.

Порядок: перед правкой парсера — `--update`, после правки — проверка; если все изменения
ожидаемые — снова `--update`. Снимок (`tools/anketa-snapshot.json`) хранится только у себя.
